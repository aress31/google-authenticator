Generate time-based one-time passwords and apply them to scoped Burp session handling rules. Supports Google Authenticator and other RFC 6238 TOTP clients, Base32 secrets and otpauth://totp provisioning URIs, SHA-1/SHA-256/SHA-512, 6 or 8 digits, and configurable periods.

  1. Enter a shared secret or TOTP provisioning URI in the Google Authenticator tab.
  2. Place {{TOTP}} in the relevant request body, or configure a literal/regex replacement. Use a named otp capture group to replace only a value within a larger regex match.
  3. Click Apply & start, then add the extension action to a session handling rule under Settings > Sessions. Restrict the rule to the intended requests and tools.

Codes are generated when requests are processed. The interface provides expiry, clipboard copy, rule testing and a request update counter. Secrets remain in memory only. Requires Java 21 and Burp Suite 2026.7 or later.
