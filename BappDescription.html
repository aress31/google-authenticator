Generate fresh time-based one-time passwords (TOTP) and insert them into requests through Burp session handling rules. Supports Google Authenticator and other RFC 6238-compatible authenticators.

  • Accepts Base32 shared secrets and otpauth://totp provisioning URIs.
  • Supports SHA-1, SHA-256 and SHA-512, with 6 or 8 digits and configurable periods.
  • Replaces literal text or regular-expression matches in request bodies, headers and URLs.
  • Provides a code countdown, clipboard copy, live rule preview and request update counter.

To get started, enter a shared secret or provisioning URI in the Google Authenticator tab and configure the text to replace, such as {{TOTP}}. Click Apply & start, then select the extension through an Invoke a Burp extension action in a session handling rule. Scope the rule to the intended requests and tools.

Codes are generated when requests are processed. Shared secrets are held in memory and are not saved in extension settings. Editing the configuration pauses request updates until it is applied again.

Requirements: Burp Suite 2026.7 or later and Java 21 or later.
